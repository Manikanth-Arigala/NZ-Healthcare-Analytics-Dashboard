# 🚑 New Zealand Healthcare Analytics Dashboard

## 📊 Overview

This project presents an interactive healthcare analytics dashboard built using Power BI.
The dataset is synthetic and designed to reflect real-world healthcare scenarios.

---

## 🔍 Key Insights

* Patient admissions show a declining trend over time
* Injury & Accident cases are the highest cost drivers
* Public hospitals handle a slightly higher share of patients
* Regional variation exists across locations
* Average hospital stay is approximately 5.4 days
* Average treatment cost per patient is ~$13.3K NZD

---

## 💡 Business Impact

This analysis helps identify cost-intensive conditions and regional demand patterns, enabling better resource allocation and data-driven decision-making in healthcare systems.
